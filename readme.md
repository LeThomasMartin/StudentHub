# StudentHub

StudentHub est un environnement numérique centralisé pour organiser les études, gérer les documents et optimiser l'apprentissage grâce à une intelligence artificielle personnelle.

## Aperçu

L'application vise à regrouper :

- le dashboard étudiant,
- la gestion des cours et du calendrier,
- la bibliothèque documentaire,
- le lecteur PDF interactif,
- les outils d'apprentissage et de mémorisation,
- l'assistant IA local.

## Objectif du projet

StudentHub doit devenir une plateforme d'apprentissage personnelle dans laquelle organisation, documents, répétition et intelligence artificielle travaillent de façon cohérente et sécurisée.
